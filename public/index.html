    Use CultureRisk inside your own agent

    CultureRisk is also an MCP server. Any MCP-capable agent, such as Claude, ChatGPT connectors or Cursor, can call it as a tool and get Qloo-grounded film intelligence in the middle of a conversation.

    Endpoint

    https://<this-site>/api/mcp

    Connect from Claude Code

    claude mcp add --transport http culturerisk https://<this-site>/api/mcp

    Tools

    ToolWhat it does
    greenlight_analysisRuns the full autonomous research agent on a project and its comps. Returns the verdict, risk score, audience portrait, recommendations with Qloo IDs, risks and next steps.
    audience_affinitiesWhat the combined audience of one or more films over-indexes on in one Qloo domain, with white-space gaps.

    Try it from a terminal

    curl -s https://<this-site>/api/mcp -H 'Content-Type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
